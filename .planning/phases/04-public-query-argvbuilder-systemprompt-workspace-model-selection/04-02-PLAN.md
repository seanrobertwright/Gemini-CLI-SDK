**Step 2: Create ts/src/query/query.ts with three exports: query, queryRaw, queryFull**

Internal helper `writeTempSystemPrompt(systemPrompt: string | undefined): Promise<string | undefined>`:
- If `!systemPrompt` (undefined or empty string), return `undefined`
- Generate suffix: `crypto.randomBytes(8).toString('hex')`
- Path: `path.join(os.tmpdir(), 'gemini-sdk-system-' + suffix + '.md')`
- Write: `await fs.writeFile(tempPath, systemPrompt, 'utf-8')`
- Return absolute tempPath

Internal shared generator `_queryCore(options, yieldRaw: boolean)`:
- This is the shared generator body used by both `query()` and `queryRaw()`.
- Alternatively, implement `query()` and `queryRaw()` as separate functions both using the same lifecycle pattern. The simpler approach: implement `query()` fully, then `queryRaw()` as a parallel function that skips `dispatch()`.

**query() implementation** — async generator yielding MessageChunk:
1. Check `options.abortSignal?.aborted` — if already aborted, throw `new AbortError()`
2. Call `writeTempSystemPrompt(options.systemPrompt)` to get `tempPath`
3. Build env overrides: start with `options.env ?? {}`, if `tempPath` exists add `GEMINI_SYSTEM_MD: tempPath`
4. Call `buildArgv(options)` to get argv
5. Create `new ProcessManager()`, call `manager.spawn({ argv, cliPath: options.cliPath, env: envOverrides, spawnOptions: { cwd: options.cwd } })`
6. Set up abort listener: `let aborted = false; const onAbort = () => { aborted = true; }; options.abortSignal?.addEventListener('abort', onAbort, { once: true });`
7. Track model: `let requestedModel = (options.model && options.model !== 'auto') ? options.model as string : undefined; let actualModel: string | undefined;`
8. **Tool chunk buffering:** Maintain `const pendingToolChunks: MessageChunk[] = []` — accumulates tool_use chunks that have not yet been paired with a tool_result. On each yielded chunk: if `chunk.type === 'tool'` (tool_use), push to `pendingToolChunks`; if `chunk.type === 'toolResult'` (tool_result), clear `pendingToolChunks` (the pair is complete).
9. In try block: `const rawEvents = parseNdjson(child.stdout!); const chunks = dispatch(rawEvents);`
10. `for await (const chunk of chunks)`: if `aborted`, break; if `chunk.type === 'system' && chunk.subtype === 'init'`, capture `actualModel = chunk.model`; if `chunk.type === 'result'`, enrich with `requestedModel`/`actualModel` when both defined and different; update `pendingToolChunks` per step 8; yield chunk
11. After loop: if `aborted`, perform abort flush (see step 12) then throw `new AbortError()`
12. **Abort flush (per user decision — Phase 3 unpaired-tool flush contract):** Before throwing AbortError, iterate `pendingToolChunks` and yield each with `{ ...chunk, incomplete: true }`. This ensures the caller sees partial tool state before the error. The `incomplete: true` flag matches Phase 3's unpaired-tool flush contract — no silent data loss.
13. Finally block: `removeEventListener`, `killTree(child.pid)` (try/catch ignore), `fs.unlink(tempPath)` (try/catch ignore)

**queryRaw() implementation** — async generator yielding RawEvent:
- Same lifecycle (temp file, spawn, abort, finally) but pipeline is just `parseNdjson(child.stdout!)` — no `dispatch()`
- No model downgrade detection (that's a high-level concern)
- No tool chunk buffering needed (raw events are unprocessed; buffering is a dispatch-level concern)

**queryFull() implementation** — async function returning Promise<QueryResult>:
```typescript
export async function queryFull(options: QueryOptions): Promise<QueryResult> {
  const chunks: MessageChunk[] = [];
  let text = '';
  let sessionId = '';
  let stopReason = '';
  for await (const chunk of query(options)) {
    chunks.push(chunk);
    if (chunk.type === 'assistant') text += chunk.content;
    if (chunk.type === 'result') {
      sessionId = chunk.sessionId;
      stopReason = chunk.stopReason;
    }
  }
  return { text, sessionId, stopReason, chunks };
}
```
