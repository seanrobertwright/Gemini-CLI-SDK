**ts/src/process/SpawnPerCallStrategy.ts:**
Implements `ProcessStrategy`. The Windows .cmd handling pattern from Phase 1 (CONTEXT.md decision):
```typescript
import { spawn, type ChildProcess, type SpawnOptions } from 'node:child_process';
import { platform } from 'node:os';
import type { ProcessStrategy } from './ProcessStrategy.js';

export class SpawnPerCallStrategy implements ProcessStrategy {
  spawn(
    argv: string[],
    env: Record<string, string>,
    options: Partial<SpawnOptions> = {}
  ): ChildProcess {
    const [cmd, ...args] = argv;
    const isWin = platform() === 'win32';

    if (isWin) {
      // Phase 1 confirmed: Windows .cmd shims require shell:true
      // CVE-2024-27980: pre-build command string, never shell:false with .cmd
      // DO NOT combine detached:true with windowsHide:true (Node issue #21825)
      const cmdStr = [cmd, ...args.map(a => `"${a}"`)].join(' ');
      return spawn(cmdStr, [], {
        shell: true,
        windowsHide: true,
        env,
        stdio: 'pipe',
        ...options,
      });
    }

    return spawn(cmd, args, {
      shell: false,
      env,
      stdio: 'pipe',
      ...options,
    });
  }
}
```

IMPORTANT: On Windows, use `"${a}"` quoting for args (not JSON.stringify which adds backslash escapes). The pre-built string is the CVE-2024-27980 mitigation per Phase 1 findings.

**ts/src/process/ProcessManager.ts:**
Orchestrates binary resolution, env building, strategy spawning, and kill lifecycle:
```typescript
export class ProcessManager {
  constructor(private strategy: ProcessStrategy = new SpawnPerCallStrategy()) {}

  spawn(options: { argv?: string[]; cliPath?: string; env?: Record<string, string>; spawnOptions?: Partial<SpawnOptions> }): ChildProcess {
    const binary = resolveBinary(options.cliPath);
    const env = buildEnv(options.env);
    const argv = [binary, ...(options.argv ?? [])];
    return this.strategy.spawn(argv, env, options.spawnOptions);
  }
}
```

The `killTree` function:

- On Unix: Send SIGTERM via `process.kill(pid, 'SIGTERM')`. Set a timeout for `gracePeriodMs`. If process is still alive after timeout, send SIGKILL via `process.kill(pid, 'SIGKILL')`. Catch ESRCH (already dead) silently.
