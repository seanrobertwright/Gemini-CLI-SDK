    ```javascript
    export function redact(text) {
      if (typeof text !== 'string') return text;
      let out = text;
      for (const r of REDACTORS) {
        out = out.replace(r.pattern, r.replacement);
      }
      return out;
    }
    ```

    **3. Exported function `redactJsonValue(value)`** — deep-walks a parsed JSON value (the result of `JSON.parse`). Rules:
       - Declare a module-level constant: `const SENSITIVE_KEYS = new Set(['session_id', 'user_id', 'account_id', 'api_key', 'access_token', 'auth_token', 'bearer_token']);`
       - For an object: iterate entries. If key is in SENSITIVE_KEYS, set the new value to the string `'<REDACTED>'`. Otherwise, recurse into the value.
       - For an array: map-recurse.
       - For a string: apply `redact()` to it.
       - For number/boolean/null: return as-is.
       - NEVER mutate the input. Start with `structuredClone(value)` for safety, then rebuild.
